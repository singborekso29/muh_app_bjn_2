# Muh-BJN App

## Nama Project
Muh-BJN App

## Framework
Laravel 12

## PHP
8.4

## Database
MySQL

## Tujuan

Muh-BJN App adalah Sistem Informasi Manajemen Sekolah berbasis web yang dikembangkan untuk SMP Muhammadiyah Bojong Nangka.

- Kepala Sekolah
- Wakil Kepala Sekolah
- Guru
- Tata Usaha
- Wali Kelas
- Siswa
- Orang Tua
